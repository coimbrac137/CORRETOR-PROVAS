# CORRETOR-PROVAS
Sistema web local para correção automática de provas via cartão-resposta (45 questões, A-E). Stack: HTML/CSS/JS + PHP (XAMPP) + Python/OpenCV. Sem APIs pagas. Cadastro de gabarito, upload de fotos dos cartões, detecção das marcações via OpenCV, cálculo de notas e exportação em TXT.
